# RL Atlas

Интерактивный курс обучения с подкреплением на русском и английском языках. Vite + Three.js, без серверной части.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Что реализовано

- Адаптивный интерфейс, программа из 9 модулей и 38 тем, поиск и фильтры.
- Переключение русского и английского языка, локальное сохранение прогресса.
- Четыре вводных урока, обзорные материалы остальных тем, справочник и проверка понимания.
- Three.js GridWorld с реальным табличным Q-learning, настройкой ε/α/γ, визуализацией политики, шаговым режимом и графиком возврата.
- Проверки переходов, терминального TD target, сходимости на фиксированном сиде и наличия переводов.

## Ограничения учебной версии

Продвинутые темы содержат обзорные тексты на уровне модуля, а не полные самостоятельные главы. Проверка понимания пока общая для всех уроков. Полноценные реализации DQN/PPO/SAC, другие среды, редактор кода и серверная синхронизация прогресса ещё не реализованы. Метрика достижения цели в лаборатории считается по всем тренировочным эпизодам, включая исследование; это не отдельная оценка качества политики.
