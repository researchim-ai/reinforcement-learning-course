# Интерактивный курс по обучению с подкреплением

Учебный квест «Последний сигнал» / The Last Signal.

Оригинальный двуязычный учебный квест по reinforcement learning. Девять секторов заброшенной исследовательской станции объединяют 38 тем, 18 проверочных задач и два настоящих интерактивных эксперимента.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## Учебный цикл

1. Исследовать доступный сектор и изучить записи.
2. Добавить изученные записи в журнал.
3. Решить вычислительную или ситуационную задачу и подтвердить рассуждение.
4. В первом секторе: обучить GridWorld-агента ≥50 эпизодов, затем отдельно проверить жадную политику без обучения. Она должна достигнуть цели за ≤100 шагов.
5. Восстановить сектор, получить артефакт и открыть следующий.

Архив всех 38 тем доступен независимо от блокировок. Последовательность прохождения и результаты заданий сохраняются в localStorage (`rl-atlas-expedition-v1`), отдельно от прогресса предыдущей версии. Журнал можно скачать в JSON. Текущее Q-обучение и данные бандитов живут в памяти вкладки; после перезагрузки нужно обучать заново, но уже полученное подтверждение испытания сохраняется.

## Реальные симуляции

- **GridWorld / Three.js:** табличный Q-learning, параметры ε/α/γ, пошаговое и непрерывное обучение, 100 эпизодов по кнопке, политика, training return, отдельная greedy evaluation.
- **Приёмники:** Bernoulli bandits, ручные испытания, UCB и ε-greedy, частоты выбора, эмпирические средние и cumulative pseudo-regret. Алгоритмы не получают истинные вероятности.
- **Станция:** оригинальная процедурная 3D-архитектура и туман, без внешних моделей и игровых ресурсов.

## Контент и доступность

Русский — основной; английская версия покрывает сюжет, материалы, задания, объяснения и интерфейс. Все 38 тем имеют материалы и математическую запись, примеры и пояснения. 34 темы после вводного модуля имеют отдельные оригинальные заметки и ограничения метода. Формулы используют KaTeX с MathML; длинные выражения прокручиваются внутри контейнера.

Синтезированный Web Audio ambient включается только по нажатию. Есть отключение движения, поддержка prefers-reduced-motion, клавиатурные фокусы и доступные подписи. Нет скримеров, вспышек или заимствованной музыки.

## Границы реализации

Это компактный вводный маршрут по широкому спектру RL, а не исчерпывающий университетский учебник. Продвинутые DQN/PPO/SAC/Dreamer и другие методы представлены учебными заметками, формулами и задачами; их нейросетевое обучение в браузере не имитируется. Нет Python-редактора, автоматической проверки программ, серверных аккаунтов или синхронизации прогресса. Проверки квеста предназначены для обучения, а не для защищённой аттестации.

## Проверки

`npm test` проверяет переходы и терминальные цели, нахождение маршрута с фиксированным seed, отсутствие изменений Q при evaluation, работу UCB, bilingual-контент и рендеринг всех формул, условия разблокировки всех девяти секторов и форму сохраняемого прогресса.

## Город и сюжетное расследование

Вкладка «Город в тумане» добавляет исследуемую 3D-улицу: фасады, трамвайные пути, фонари, телефонную будку, схему района, оставленную запись, учебный терминал и шлюз. Процедурные текстуры и геометрия создаются в проекте. Туман сочетает глубинный FogExp2 и несколько шейдерных слоёв с шумом; его плотность настраивается и сохраняется локально. Статическая геометрия объединяется по материалам, уменьшая число вызовов отрисовки.

Управление: WASD / стрелки (также поддержаны клавиши русской раскладки), перетаскивание сцены для обзора, E для взаимодействия с ближайшим объектом. Экранные кнопки и выбор точки интереса позволяют играть на телефоне. При отключённом движении переход к выбранному объекту происходит сразу. Если WebGL недоступен, объекты и сюжет остаются доступны через список.

Оригинальная история: инженер Мира, диспетчер Лев и городской контур ЭХО. В девяти главах — 36 реплик, 18 вариантов ответов и девять документов. Сохранённый ответ отражается в следующей главе. Учебные испытания открывают районы, изменяют освещение и шлюзы. Два финала доступны после всех девяти учебных испытаний; финал с передачей архива дополнительно требует минимум четырёх сохранённых документов из разных районов.

История хранится отдельно в `rl-atlas-city-story-v1`, старый учебный прогресс сохраняется. «Журнал расследования» содержит найденные записи, расшифровки и выбранные ответы. Это текстовые переговоры, без синтезированной речи; включаемый пользователем ambient из предыдущей версии сохранён. Районы используют общий тип улицы с процедурными вариациями фасадов и собственными сюжетными материалами; свободного открытого мира или входов в интерьеры пока нет.
